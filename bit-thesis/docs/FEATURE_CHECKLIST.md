# 功能总清单（bit-thesis）
本文档用于记录当前项目已实现能力，作为后续重构与打包阶段的回归基线。

## 1. 编辑与模式
- [x] 填空模式与 Typst 模式双向切换
- [x] 填空模式卡片类型：文本、标题、图片、公式、三线表、Typst 卡片
- [x] 卡片拖拽排序（含拖到末尾）
- [x] 文本卡片展开/折叠与自动高度
- [x] 卡片级转换：结构化 -> Typst
- [x] 卡片级转换：Typst -> 结构化

## 2. 右键菜单与插入
- [x] 在后方插入：文本/标题/图片/公式/三线表
- [x] 在光标处插入：文本/标题/图片/公式/三线表
- [x] 右键“粘贴到光标处”
- [x] 选中文本后右键转一级/二级/三级标题（自动分割前后文本）
- [x] 右键素材预览插入（结构化模式）
- [x] Typst 模式右键菜单（按 Typst 语法插入）
- [x] Typst 模式素材预览插入

## 3. 粘贴与文本规范化
- [x] 普通粘贴强制纯文本写入（去富文本格式）
- [x] Ctrl+V 识别图片并自动上传素材库
- [x] 图文混合粘贴：文本插入 + 图片生成卡片 + 后续文本拆卡
- [x] 异常字符检测（字体回退风险提示）
- [x] 一键文本规范化
- [x] 强制统一字体字符修复（异常字符替换）

## 4. 图片、图表与题注
- [x] 图片上传并缓存（`assets-cache`）
- [x] 图片默认宽度 100%
- [x] 图片卡片支持素材联动重命名（已连接素材时）
- [x] 图/表自动编号开关（默认开启）
- [x] 图题注位置可选（上/下）
- [x] 表题注位置可选（上/下）
- [x] 三线表默认线型：上/下 1.5pt，表头下 0.75pt

## 5. 素材库
- [x] 素材上传
- [x] 素材列表与搜索
- [x] 素材右键菜单：插入图片块、复制路径、重命名、删除
- [x] 外置重命名输入区（便于查看与输入）

## 6. PDF 预览与定位
- [x] Typst 实时渲染正文 PDF
- [x] 左编辑 / 右预览并排
- [x] 预览缩放：适应宽度 / 整页
- [x] 预览滚动页码跟随
- [x] 编辑与预览定位联动（页级 + 句子近似锚点）

## 7. 导入导出
- [x] 封面上传（仅 PDF）
- [x] 正文 PDF 可选上传（可覆盖实时渲染结果）
- [x] 仅导出正文 PDF
- [x] 一键导出：有封面则合并，无封面自动导出正文
