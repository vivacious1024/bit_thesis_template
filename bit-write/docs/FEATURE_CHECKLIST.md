# 功能总清单（bit-write）

本文档用于记录当前项目已经实现的能力，作为功能检查、回归测试和后续演进的基线。

## 1. 编辑与模式

- [x] 填空模式与 Typst 模式双向切换
- [x] 填空模式支持文本、标题、图片、公式、三线表、Typst 卡片
- [x] 卡片拖拽排序，支持拖到末尾
- [x] 文本卡片展开 / 折叠与自适应高度
- [x] 单卡片可转为 Typst
- [x] Typst 卡片可转回结构化卡片

## 2. 右键菜单与插入

- [x] 在后方插入文本、标题、图片、公式、三线表
- [x] 在光标处插入文本、标题、图片、公式、三线表
- [x] 右键“粘贴到光标处”
- [x] 选中文本后可直接转为一级 / 二级 / 三级标题
- [x] 结构化模式支持从素材库预览插入图片
- [x] Typst 模式支持按 Typst 片段插入内容
- [x] Typst 模式支持从素材库插入图片片段

## 3. 粘贴与文本规范化

- [x] 普通粘贴按纯文本写入
- [x] Ctrl+V 可识别图片并自动上传素材库
- [x] 图文混合粘贴可自动拆分为文本卡片与图片卡片
- [x] 检测可能导致字体回退的异常字符
- [x] 一键文本规范化
- [x] 强制统一字体字符修复

## 4. 图片、图表与题注

- [x] 图片上传并缓存到 `assets-cache`
- [x] 图片默认宽度为 `100%`
- [x] 图片卡片支持与素材库联动重命名
- [x] 图片 / 表格自动编号开关
- [x] 图片题注位置可选上 / 下
- [x] 表格题注位置可选上 / 下
- [x] 三线表默认线型为上 / 下线 `1.5pt`、表头下线 `0.75pt`

## 5. 素材库

- [x] 素材上传
- [x] 素材列表与搜索
- [x] 素材右键菜单：插入图片块、复制路径、重命名、删除
- [x] 独立重命名输入区，便于长文件名编辑
- [x] 素材库存储路径可自定义
- [x] Windows 环境支持系统文件夹选择器

## 6. PDF 预览与定位

- [x] Typst 实时渲染正文 PDF
- [x] 左侧编辑 / 右侧预览并排布局
- [x] 预览缩放：适应宽度 / 整页
- [x] 预览滚动页码跟随
- [x] 编辑区与预览区定位联动

## 7. 导入与导出

- [x] 封面上传，仅支持 PDF
- [x] 外部正文 PDF 可选上传，上传后优先使用
- [x] 仅导出正文 PDF
- [x] 一键导出：有封面则合并，无封面则直接导出正文

## 8. 本地接口

- [x] `POST /api/body/render-typst`
- [x] `POST /api/assets/upload-image`
- [x] `GET /api/assets/list`
- [x] `GET /api/assets/config`
- [x] `POST /api/assets/config`
- [x] `POST /api/assets/pick-directory`
- [x] `POST /api/assets/rename`
- [x] `POST /api/assets/delete`
