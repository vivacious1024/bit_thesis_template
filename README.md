# 北京理工大学本科毕业设计（论文）Typst 模板

这个仓库的核心是一套可直接使用的北京理工大学本科毕业设计（论文）`Typst` 模板，同时配套了示例文档和一个离线桌面写作工具 `bit-write`。

仓库的定位分成两层：

- 模板层：提供论文排版模板、参考文献样式和示例
- 应用层：提供基于该模板的 GUI / Electron 写作工具 `bit-write`

如果你只想直接使用模板写论文，重点看根目录模板文件和 `example/`。  
如果你想用图形界面进行编辑、预览、导出，重点看 [`bit-write/README.md`](./bit-write/README.md)。

## 仓库结构

- `template_for_bit_graduate_project.typ`
  模板主文件，是整个项目的核心。
- `china-national-standard-gb-t-7714-2015-numeric.csl`
  参考文献样式文件，用于 GB/T 7714-2015 数字顺序制。
- `example/`
  模板示例，包括示例论文和参考文献数据。
- `bit-write/`
  当前主推的离线桌面写作工具，内置本模板。

## 模板实现的重点格式

这套 Typst 模板不是只提供“能编译”的骨架，而是已经把论文里最关键的一批版式参数固化了。

### 页面与版心

- 纸张：`A4`
- 页边距：
  左 `30mm`
  右 `26mm`
  上 `35mm`
  下 `26mm`

### 页眉与页脚

- 页眉内容：`北京理工大学本科生毕业设计（论文）`
- 页眉字体：`SimSun`
- 页眉字号：`14pt`
- 页眉字距：`0.5pt`
- 页眉下方带 `0.5pt` 下边线
- 页脚字体：`SimSun`
- 页脚字号：`10.5pt`
- 页码居中显示

### 正文字体与段落

- 正文字体族：中文 `SimSun`，西文 `Times New Roman`
- 正文字号：`12pt`
- 语言：`zh`
- 段落两端对齐
- 首行缩进：`2em`
- 段落行距参数：`leading: 10pt`
- 列表与枚举缩进：`2em`

### 标题体系

- 一级标题编号格式：`第1章`
- 二级及以下标题编号格式：`1.1`、`1.1.1`
- 标题字体：`SimHei`
- 标题字重：加粗
- 一级标题字号：`16pt`
- 二级标题字号：`14pt`
- 三级标题字号：`12pt`
- 一级标题居中
- 二、三级标题左对齐
- 标题段落不首行缩进
- 一级标题出现时会重置公式编号计数

### 题名与首页信息

- 如果传入标题，模板会在正文前自动生成居中的题名区
- 题名字体：`SimHei`
- 题名字号：`20pt`
- 题名加粗
- 日期字号：`14pt`

### 图、表与题注

- 图表按章编号，格式如 `1-1`
- 图片题注前缀：`图`
- 表格题注前缀：`表`
- 题注字体：`SimSun`
- 题注字号：`10.5pt`
- 表题默认放在表格上方
- 图表整体默认居中
- 图表上下默认各留 `32pt` 间距

### 三线表

模板内置了 `bit_three_line_table(...)`：

- 上边线：`1.5pt`
- 表头下边线：`0.75pt`
- 下边线：`1.5pt`
- 默认按论文常用三线表规范生成

### 公式与交叉引用

- 公式按章编号，格式如 `(1-1)`
- 引用公式时自动显示为 `式(1-1)` 这种形式
- 一级标题切换时，公式编号按章重新开始

### 目录

- 目录项对标题做分级缩进
- 目录中自动填充点线并显示页码
- 目录缩进基准：`1em`

### 参考文献

- 使用 `china-national-standard-gb-t-7714-2015-numeric.csl`
- 采用 GB/T 7714-2015 数字顺序制
- “参考文献”标题字体：`SimHei`
- “参考文献”标题字号：`16pt`
- 标题加粗

### 附录

- 附录一级标题格式：`附录A`
- 附录内图号格式：`A-1`
- 附录内公式号格式：`(A-1)`

## 快速开始

确保本机已经安装 `Typst`，然后在仓库根目录执行：

```bash
typst compile example/example_report.typ example/example_report.pdf --root .
```

这会基于根目录模板编译示例文档。

## bit-write 桌面工具

`bit-write` 是这套模板的应用化实现，目标不是替代 Typst，而是让“不想直接手写 Typst 的用户”也能方便使用这套模板。

当前已经支持：

- 结构化填空编辑与 Typst 编辑双向切换
- 正文实时 PDF 预览
- 封面 PDF 上传
- 图片素材库上传、重命名、删除
- 素材库存储目录自定义
- 仅导出正文 PDF
- 封面 PDF 与正文 PDF 合并导出
- Windows 安装包与桌面快捷方式

详细说明见：

- [`bit-write/README.md`](./bit-write/README.md)
