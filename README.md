# 北京理工大学本科毕业设计（论文）Typst 模板

这是一个以 `Typst` 模板为核心、同时配套离线桌面写作工具的项目仓库。

这个仓库的主题是：

- 提供一套可直接编译使用的北京理工大学本科毕业设计（论文）Typst 模板
- 提供示例文档，方便快速上手和检查效果
- 提供一个基于该模板的轻量离线 GUI / 桌面应用 `bit-write`，降低实际写作门槛

如果你只是想直接写论文，根目录模板就可以使用。  
如果你希望通过图形界面编辑、预览和导出，可以重点查看 `bit-write/`。

## 仓库结构

整个仓库目前主要分为 4 个部分：

- `template_for_bit_graduate_project.typ`
  模板主文件，是整个项目的核心。
- `china-national-standard-gb-t-7714-2015-numeric.csl`
  参考文献样式文件，用于 GB/T 7714-2015 数字顺序制。
- `example/`
  模板示例，包含示例论文和参考文献数据。
- `bit-write/`
  基于该模板做的离线桌面写作工具，是本仓库的应用化亮点。

此外还有一个：

- `bit-thesis/`
  较早期的 GUI 版本与开发副本，保留用于历史对照和功能演进参考。

如果你只是第一次访问这个仓库，建议优先看这两个入口：

1. 模板使用：根目录模板文件 + `example/`
2. 桌面应用：[`bit-write/README.md`](./bit-write/README.md)

## 模板部分

根目录下的模板部分适合这些场景：

- 你已经会用 Typst
- 你希望直接维护 `.typ` 文件
- 你想把模板集成到自己的 Typst 工作流里

关键文件：

- `template_for_bit_graduate_project.typ`
- `china-national-standard-gb-t-7714-2015-numeric.csl`
- `example/example_report.typ`
- `example/ref.bib`

## 快速开始

确保本机已安装 `Typst`，然后在仓库根目录执行：

```bash
typst compile example/example_report.typ example/example_report.pdf --root .
```

这会基于根目录模板编译示例文档。

## 模板特性

当前模板已经覆盖了论文写作中的一些核心排版需求，包括：

- 北京理工大学本科毕业设计（论文）页面版式
- 多级标题与编号控制
- 图表按章编号
- 三线表支持
- GB/T 7714-2015 参考文献样式

如果你想进一步了解模板能力，可以直接阅读示例文档，或者在 Typst 中打开模板文件查看定义。

## 桌面应用亮点

除了模板本身，这个仓库还有一个更偏“实际使用”的亮点：`bit-write`。

`bit-write` 是一个基于本模板的轻量离线桌面写作工具，已经可以打包为 Windows 桌面应用。它的目标不是替代 Typst，而是让“不想直接手写 Typst 的用户”也能更方便地使用这套模板。

目前桌面应用已经支持：

- 结构化填空编辑与 Typst 编辑双向切换
- 正文实时预览
- 封面 PDF 上传
- 图片素材库管理
- 素材库存储路径自定义
- 封面 PDF 与正文 PDF 合并导出
- Electron 桌面打包
- 内置 `Typst`，目标电脑无需单独安装

如果你想看桌面应用的结构、运行方式和打包说明，请进入：

- [`bit-write/README.md`](./bit-write/README.md)

## 各目录是做什么的

为了方便上传 GitHub 后别人快速理解，下面把最外层目录再简单说明一次：

- `example/`
  模板示例与演示文稿。
- `bit-write/`
  当前主推的离线桌面应用实现。
- `bit-thesis/`
  早期 GUI 版本，主要用于保留旧实现和演进过程。
- `.cache/`
  本地运行时可能产生的缓存，不属于模板本体。
